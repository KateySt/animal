Local run: `make dev` serves `app.main:app` (plain REST, no Socket.IO). The LiveKit voice/chat agent lives in `../animal-agent/` (separate uv project, run it in its own terminal). Start infra with `docker compose -f docker/docker-compose.yml up -d postgres redis minio minio-init` (LiveKit is LiveKit Cloud via `LIVEKIT_URL`, no local server); a bare `up` also builds the containerised API on :80. Full-stack guide: `../README.md`.

Agent contract: the agent talks to this API only over HTTP (`X-Agent-Token`) via `app/routers/v1/agent_internal_router.py` + `app/schemas/agent.py`; the other side is `../animal-agent/src/api_client.py` + `src/api_models.py` - change both together. Dev: `LIVEKIT_AGENT_NAME=animal-chat-agent-dev` in `animal/.env` and `animal-agent/.env`.

Deleting chat data: any deletion of a chat document, chat session or user must go through `app.services.document_purger.document_purger` BEFORE the DB delete (API services and the admin `before_delete` hooks already do). It removes vectors in book-rag and PDFs in the private MinIO bucket; DB cascades alone leave them behind.
